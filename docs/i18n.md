# 国际化（i18n）与翻译流程

| 项目 | 值 |
| --- | --- |
| 支持语言 | `en`（默认）、`zh_CN`（简体中文） |
| 实现 | Python 标准库 `gettext` + 编译后的 `.mo` |
| 目录 | `src/vbios_studio/i18n/locale/<lang>/LC_MESSAGES/vbios_studio.po|.mo` |
| msgid 数量 | 279（`en` 与 `zh_CN` 完全一致） |
| 运行时切换 | `vbios_studio.i18n.set_language()`；GUI 重建窗口 |
| 完整性测试 | `tests/i18n/test_catalog.py` |

## 1. 设计原则

1. **所有用户可见文案走 gettext**：按钮、标签、错误对话框、状态栏、About、确认框、日志中的人类可读文本。
2. **msgid 使用稳定英文 key**，采用点分小写命名：`app.title`、`field.power_max_w`、`error.nvflash_missing`。
3. **代码里不写中文/英文 UI 文案**；新增字符串必须同时加入 `en` 与 `zh_CN` 目录。
4. **字段 key / 错误 code / 命令 / 路径**不翻译；风险等级 T0–T3 保留英文编号，徽章文案翻译。
5. **语言切换即时生效**：GUI 重建主窗口（保留 controller 状态），无需重启应用。

## 2. 目录与文件

```text
src/vbios_studio/i18n/
├── __init__.py                      # set_language/gettext/ngettext/language_name
├── catalog.py                       # locale 归一化、环境检测
└── locale/
    ├── en/LC_MESSAGES/vbios_studio.po
    ├── en/LC_MESSAGES/vbios_studio.mo
    ├── zh_CN/LC_MESSAGES/vbios_studio.po
    └── zh_CN/LC_MESSAGES/vbios_studio.mo
```

- `.po` 是源文件（提交到仓库）；`.mo` 是编译产物（也提交，保证发布包无需 gettext 工具即可运行）。
- `gettext.translation(..., fallback=True)`：目录缺失时回退到 msgid，不崩溃。
- 语言检测顺序：`VBIOS_STUDIO_LANG`（仅接受 `en`/`zh_CN`）→ `LC_ALL` → `LC_MESSAGES` → `LANG` → 默认 `en`。

## 3. 运行时入口

| 场景 | 方式 |
| --- | --- |
| CLI/GUI 启动 | `vbios-studio-gui --lang zh_CN` |
| 环境变量 | `VBIOS_STUDIO_LANG=zh_CN ./bin/vbios-studio-gui` |
| GUI 菜单 | “Language / 语言” 菜单即时切换 |
| 代码内 | `from vbios_studio.i18n import gettext as _; _("app.title")` |

## 4. 新增一条文案

1. 在代码中使用新的稳定 msgid（英文 key），例如：

   ```python
   from vbios_studio.i18n import gettext as _
   label = _("apply.warning.modified_image")
   ```

2. 在 `src/vbios_studio/i18n/locale/en/LC_MESSAGES/vbios_studio.po` 增加：

   ```po
   msgid "apply.warning.modified_image"
   msgstr "This is a modified image. Never flash it with nvflash."
   ```

3. 在 `zh_CN` 的同一文件增加中文 `msgstr`。
4. 编译 `.mo`（二选一）：

   ```bash
   # GNU gettext（推荐；Debian/Ubuntu: sudo apt install gettext）
   msgfmt -c -o src/vbios_studio/i18n/locale/en/LC_MESSAGES/vbios_studio.mo \
       src/vbios_studio/i18n/locale/en/LC_MESSAGES/vbios_studio.po
   msgfmt -c -o src/vbios_studio/i18n/locale/zh_CN/LC_MESSAGES/vbios_studio.mo \
       src/vbios_studio/i18n/locale/zh_CN/LC_MESSAGES/vbios_studio.po
   ```

   或使用 Babel（若环境已安装）：

   ```bash
   python -m babel.messages.frontend compile \
       -i src/vbios_studio/i18n/locale/en/LC_MESSAGES/vbios_studio.po \
       -o src/vbios_studio/i18n/locale/en/LC_MESSAGES/vbios_studio.mo
   ```

5. 跑完整性测试：

   ```bash
   python -m pytest -q tests/i18n
   ```

   测试会检查：
   - `en` 与 `zh_CN` 的 msgid 集合完全一致；
   - 两边每个 msgstr 都非空；
   - 源码中出现的所有点分 msgid 都能在目录中找到。

## 5. 添加一种新语言（未来）

1. 复制 `en` 目录为 `locale/<lang>/LC_MESSAGES/`。
2. 更新 `src/vbios_studio/i18n/__init__.py` 的 `LANGUAGES` 与 `LANGUAGE_NAMES`。
3. 翻译全部 msgid（不要保留英文占位）。
4. 更新 `docs/i18n.md` 与本表。
5. 跑 `tests/i18n` 与 `tests/ui/test_language.py`。
6. 语言代码使用 POSIX 形式（`zh_CN`、`ja_JP`），不要用 `zh-CN`。

## 6. 翻译风格

- **中文**：简洁、专业、避免口语；风险说明必须保留强度（“严禁”“可能导致永久损坏”不能弱化）。
- **英文**：Sentence case；按钮用动词原形（Open / Save As / Apply）。
- **术语一致**：VBIOS、ROM、T0–T3、override、payload、checksum、nvflash 保留英文；`flash` 可译为“刷写”，`override` 可译为“覆盖/override”。
- **数字与单位**：`W`、`mV`、`mA`、`MHz`、`RPM`、`°C` 不翻译；范围用 `–`。
- **错误文案**：说明“发生了什么 + 为什么 + 建议动作”，不要只写“失败”。

## 7. 已知限制

- 当前只支持 `en` / `zh_CN`；`tests/ui/test_language.py` 只验证这两种。
- `.po`/`.mo` 需同时更新；若只改 `.po` 而未编译 `.mo`，运行时会看到旧文案。
- gettext 的 `msgid` 是英文 key，不是英文自然语言；调试时直接搜 key 即可。
- 翻译不覆盖第三方上游 GUI（`src/nvidia_vbios/gui/`，本项目不 import）。
